# Mój projekt

Tu będzie Twój własny projekt: wyzwanie od mentora albo Twój pomysł.
Na start wystarczy, że odpowiesz krótko na cztery pytania (możesz też poprosić agenta, żeby przeprowadził Cię przez nie rozmową):

1. Jaki problem rozwiązujemy i dla kogo?
2. Jaką decyzję produktową chcemy podjąć dzięki tej pracy?
3. Co już wiemy (dane, badania, obserwacje), a co tylko zakładamy?
4. Jak poznamy, że rozwiązanie działa?
