# Mój projekt

Tu będzie Twój własny projekt: wyzwanie od mentora albo Twój pomysł.

- **Wyzwanie od mentora:** dostaniesz plik `wyzwanie.md`. Wgraj go do tego folderu.
- **Własny pomysł:** skopiuj `wyzwanie-szablon.md` jako `wyzwanie.md` i uzupełnij pola. Możesz poprosić agenta: „Przeprowadź mnie rozmową przez szablon wyzwania i zapisz wynik jako moj-projekt/wyzwanie.md”.

Plik `wyzwanie.md` to dla agenta główne źródło wiedzy o Twoim projekcie, tak jak `papuga/case.md` dla Papugi.
